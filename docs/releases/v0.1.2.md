NIP para llamadas de amigos con servidores autohospedados. MVP para Windows x64: una sala de audio e invitaciones privadas. La conectividad comprobable es local/LAN; no incluye STUN/TURN ni garantiza llamadas desde internet.

## Descargar e instalar

Descargá **NIP-Setup-0.1.2-x64.exe** en Assets y ejecutalo. No necesitás Node.js ni permisos de administrador. Se instala en tu cuenta y crea accesos directos. Abrí NIP desde el menú Inicio o el escritorio. Para desinstalar: Configuración > Aplicaciones > NIP. Los datos locales se conservan.

## Firma y verificación

**Instalador sin firma Authenticode.** Windows/SmartScreen y antivirus pueden advertirlo. SignPath Foundation es la opción solicitada para firma futura; no está aprobado ni activo. No se promete ausencia de advertencias. [Code signing policy](https://github.com/santipk/nip/blob/main/CODE_SIGNING.md).

El archivo `SHA256SUMS.txt` permite comprobar integridad con `Get-FileHash -Algorithm SHA256 .\NIP-Setup-0.1.2-x64.exe`. El hash no sustituye una firma digital ni una auditoría de seguridad.

Esta release se construye desde su tag en GitHub Actions. El proceso exige typecheck, los cinco tests de integración y una prueba del instalador real: instalación por usuario, accesos directos, arranque/servidor y desinstalación con perfil de prueba aislado. No demuestra micrófono/parlantes físicos, conectividad WAN ni comportamiento de SmartScreen al descargar.
