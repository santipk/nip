    Usá una IP local para LAN. Para internet, ingresá tu IP pública o dominio y configurá tu red.

    Quien tenga este enlace puede entrar y compartirlo. No incluye claves privadas.

    Conexión desde internet

    Servidor iniciado no significa accesible desde internet. Necesitás permitir el puerto TCP elegido y, según tu red, configurar redirección de puertos y DNS dinámico. Con CGNAT puede hacer falta una red privada o una solución propia del anfitrión. El audio directo requiere conectividad entre los clientes; este MVP no incluye relay ni garantiza atravesar NAT. Verificá desde otra red con un amigo.
